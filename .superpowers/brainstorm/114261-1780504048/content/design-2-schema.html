设计 · 第2节：数据模型

ScheduleStore 管理的两张 SQLite 表

📋 schedule_config — 定时计划

字段类型说明示例
id INTEGER PK 自增主键 1
device_type TEXT "pump" 或 "lamp" pump
days_of_week TEXT "1,2,3,4,5,6,7" (周一=1) 1,3,5
start_time TEXT HH:MM 格式 07:00
duration_min INTEGER 持续时长（分钟） 30
enabled INTEGER 1=启用 / 0=停用 1
created_at TEXT 创建时间 ISO 格式 2026-06-04T10:00:00

📜 schedule_log — 执行日志

字段类型说明示例
idINTEGER PK自增主键1
device_typeTEXT"pump" / "lamp"pump
schedule_idINTEGERFK → schedule_config.id (手动则为NULL)1
actionTEXT"on" / "off"on
triggerTEXT"schedule" / "manual"schedule
flow_rateREAL当时流速 (L/min)，lamp为02.5
volume_lREAL本次累计灌溉量(L)，lamp为037.5
tsTEXT操作时间 ISO 格式2026-06-04T07:00:00

⚙️ 全局配置 — QSettings

键名类型默认值说明
pump/flow_ratedouble2.5灌溉泵流速 (L/min)
schedule/check_intervalint60调度检查间隔 (秒)
schedule/db_pathstring./schedule.dbSQLite 文件路径
