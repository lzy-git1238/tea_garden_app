华为云 IoT 命令下发 — 现状 & 目标

在现有属性上报（上行）基础上，新增云端命令接收（下发）+ 响应

🔄 现状：仅上行
# 属性上报 topic
$oc/devices/{id}/sys/properties/report
# 方式
mosquitto_pub -l (stdin 写入)
# 数据流
RK3588
  └─ IotUploader::upload()
     └─ mosquitto_pub → 华为云 ⬆️
❌ 无法接收云端下发指令
🎯 目标：双向通信
# 属性上报 topic (不变)
$oc/devices/{id}/sys/
properties/report
# 命令接收 topic (新增)
$oc/devices/{id}/sys/
commands/#
# 命令响应 topic (新增)
$oc/devices/{id}/sys/
commands/response/{rid}
✅ 接收 pump_control / light_control
✅ 转发到 LoRa → 灌溉泵/灭虫灯
✅ 返回 result 给云端

📋 华为云 IoT 命令协议格式

云端下发 pump_control / light_control
// 云端下发的 MQTT 消息 (command topic)
{
  "paras": { "value": true },
  "service_id": "pump_control",
  "command_name": "pump_control",
  "request_id": "abc123..."
}
// 设备端响应 (response topic)
{
  "result_code": 0,
  "response_name": "pump_control",
  "paras": { "result": 0 }
}
