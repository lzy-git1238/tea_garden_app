## 二、说明

智慧茶园综合管理系统 V1.0适用于智慧农业 / 物联网应用 / 边缘计算与人工智能场景。用户进入系统后，可以围绕实际工作内容完成账号进入、业务创建、过程查看、结果确认和资料管理等操作。

日常使用时，茶园管理人员：日常巡检、环境监控、灌溉和驱虫灯控制、农业技术人员：病虫害监测数据分析、灌溉方案制定、农场经营者：远程查看茶园状态、接收异常告警可以按照页面提示从入口进入相应页面，查看当前业务状态，并根据页面中的按钮、输入框、列表或弹窗继续处理。将边缘 AI 推理（YOLO病虫害检测）、LoRa物联网感知、MQTT云平台协同和 DeepSeek 大语言智能服务深度融合，替代传统人工巡检，实现茶园环境实时监控、病虫害自动识别、设备远程控制和 AI 智能决策，降低人力成本，提升管理效率。

基于 RK3588 边缘 AI 开发板的茶园全场景智能管控平台，集环境感知、视频分析、设备控制、云平台协同和 AI 决策于一体，面向茶园数字化转型提供一站式边缘计算解决方案。

本操作手册配套以下技术文档，供茶园管理人员和技术人员参考使用。

智慧茶园综合管理系统是一款运行于 RK3588 边缘计算设备的茶园智能化管理软件。软件通过 LoRa 无线网络连接茶园中部署的环境传感器，实时采集空气温湿度、光照强度、风速、土壤湿度/温度/电导率/pH等环境数据，并在主界面上以数据卡片形式直观展示。

软件接入农业无人机的 SRT 视频流和地面检测车的 USB 摄像头画面，利用设备内置的 NPU 神经网络处理器运行 YOLO 深度学习智能服务，对视频画面中的茶树病虫害进行实时识别和定位。检测结果关联无人机 GPS 位置后在高德地图上以标记点展示，帮助管理者快速定位病虫害发生位置。

环境实时监控：系统通过 LoRa 无线网络每3秒采集一次茶园传感器数据，包括空气温湿度、光照、风速、土壤湿度/温度/电导率/pH共8项环境指标，在主界面左侧面板以数据卡片形式实时刷新显示。数据同时存入本地 SQLite 数据库，支持历史回溯。

视频监控与 AI 病虫害识别：系统支持接入无人机SRT H.264视频流和地面检测车 USB 摄像头画面，在主界面右侧视频区域实时播放。视频帧送入 NPU 运行 YOLOv5s 病虫害检测智能服务，可实时识别茶藻斑病、茶炭疽病、茶灰斑病、茶小绿叶蝉、茶红叶斑等6类病虫害目标。检测结果与无人机 GPS 坐标绑定，在高德地图上以标记点可视化展示。同种病虫害在同一位置（0.5米范围内）自动去重，避免重复记录。

本手册用于说明软件的用途、功能特点、运行要求和页面操作流程。各功能章节按用户能够看到的页面、入口、按钮、输入项、提示信息和处理结果进行说明。

## 三、功能特点

用户可在主界面仪表盘页面系统启动后的主操作界面，三栏布局集中展示茶园所有实时信息和控制入口，是用户日常使用的主要页面。页面上的左侧面板：8张环境数据卡片（风速、空气温度、空气湿度、光照强度、土壤湿度、土壤温度、土壤电导率、土壤pH），每张卡片显示传感器名称、当前数值和单位、左侧面板底部：LoRa连接状态标签、📊数据看板按钮、🐛病虫害按钮、🚗小车控制按钮、左侧面板设备控制区：灌溉泵开关按钮（蓝色/灰色切换）、驱虫灯开关按钮（黄色/灰色切换）、各设备右侧的⏰定时按钮、左侧面板流量状态卡片：灌溉进行中显示已灌溉量、预计总量、剩余时间、进度条和停止/设置按钮和中间面板：高德地图（显示茶园位置和病虫害标注点）、天气卡片（天气等级、详情和时间）会集中呈现当前可操作内容，用户处理完成后可以看到传感器数值实时刷新，正常数据显示为白色，超阈值数据显示为红色、设备按钮切换颜色和文字（开/关），按钮按下后状态即时反馈和 LoRa 状态标签显示当前连接端口和波特率。

在数据折线看板页面中，用户主要处理以折线图形式展示8项传感器历史数据趋势，支持时间范围选择、阈值标记和 Excel 导出，帮助用户分析茶园环境变化规律。系统把顶部工具栏：1小时/6小时/24小时/7天/30天时间预设按钮、自定义起始和结束时间选择器、查询按钮、阈值设置按钮、导出 Excel 按钮、主体区域：8张可折叠的折线图卡片（风速、空气温度、空气湿度、光照强度、土壤湿度、土壤温度、土壤电导率、土壤pH），每张卡片顶部有标题栏（点击可折叠/展开）、每张图表：折线数据线、超阈值红色散点标记、Y轴数值刻度、X轴时间刻度、底部横向滚动条：用于滑动浏览长时间范围的数据和图表卡片右下角：拖拽调整卡片高度的手柄放在当前操作区域，处理结束后会反馈选择预设时间或自定义查询后，8张图表同步刷新，折线动态重绘、导出 Excel 完成后弹出文件保存路径提示和修改阈值后图表中的红色阈值线和超限标记立即更新。

病虫害监测看板页面关注的是展示 YOLO 检测到的所有病虫害记录，以统计饼图和明细表格形式呈现，帮助用户掌握茶园病虫害发生情况。用户通过顶部：病虫害总检测次数统计数字、左侧：病虫害种类分布饼图（按种类用不同颜色扇形展示占比）、右侧：病虫害记录明细表格（包含序号、种类、数量、纬度、经度、检测时间列）和底部：清除数据按钮、窗口关闭按钮确认当前状态，并在操作结束后获得新病虫害检测到后，看板内统计数据自动更新（重新打开窗口时刷新）、清除数据后饼图重置为空，表格清空和地图上的病虫害标记与看板数据同步（地图上点击标记可查看详情）。

用户可在地面小车控制面板页面遥控地面检测车在茶园中行进和喷水作业，同时实时查看检测车 USB 摄像头画面。页面上的上半部分：USB摄像头实时视频画面（640×480），显示检测车前方视野、下半部分：5个方向控制按钮（前进▲、后退▼、左转◀、右转▶、喷水💧），按钮以十字形排列和底部：状态提示标签会集中呈现当前可操作内容，用户处理完成后可以看到按钮按下时颜色高亮，松开恢复，视觉反馈明确、视频画面实时更新，延迟约100-200毫秒和 LoRa 发送失败时无特殊提示，小车不响应运动指令。

在定时计划管理页面中，用户主要处理管理灌溉泵和驱虫灯的定时自动执行计划，支持按星期多时段配置，查看执行历史记录和统计图表。系统把顶部：设备类型下拉筛选框（灌溉泵/驱虫灯/全部）、标签页一（计划管理）：设备筛选框、新增计划按钮、计划列表表格（设备类型、星期、时间、时长、启用状态列）、编辑和删除操作按钮和标签页二（历史记录）：设备类型筛选框、时间范围下拉选择框、灌溉量/运行时长统计图表、执行日志文本区域、汇总统计标签放在当前操作区域，处理结束后会反馈新建或编辑计划后，计划列表表格即时刷新、计划时间到达时，主界面设备按钮自动切换状态，流量卡片出现（灌溉）和计划执行完成后，日志自动写入历史记录标签页。

阈值设置页面关注的是为8项环境传感器分别设置上下限阈值，用于数据看板中超限红色标记和主界面弹泡告警。用户通过8行传感器阈值设置项，每行包含：传感器名称标签、下限数值输入框、上限数值输入框、单位标签和底部：保存按钮、取消按钮、恢复默认按钮确认当前状态，并在操作结束后获得保存成功后对话框关闭，数据看板的图表即时更新红色阈值线和超限标记、阈值超限时主界面系统托盘弹出气泡，显示传感器名称和数值的超限信息和同一传感器超限告警有冷却时间，短时间内不会重复弹泡。

## 五、主界面仪表盘

用户可在主界面仪表盘页面系统启动后的主操作界面，三栏布局集中展示茶园所有实时信息和控制入口，是用户日常使用的主要页面。用户可以通过系统启动后自动全屏显示，无需手动进入。

茶园管理人员打开系统后在此页面查看茶园实时环境数据、无人机/检测车视频画面、地图标注和天气信息，进行设备开关操作和 AI 咨询。

用户在主界面仪表盘页面会看到左侧面板：8张环境数据卡片（风速、空气温度、空气湿度、光照强度、土壤湿度、土壤温度、土壤电导率、土壤pH），每张卡片显示传感器名称、当前数值和单位、左侧面板底部：LoRa连接状态标签、📊数据看板按钮、🐛病虫害按钮、🚗小车控制按钮、左侧面板设备控制区：灌溉泵开关按钮（蓝色/灰色切换）、驱虫灯开关按钮（黄色/灰色切换）、各设备右侧的⏰定时按钮、左侧面板流量状态卡片：灌溉进行中显示已灌溉量、预计总量、剩余时间、进度条和停止/设置按钮、中间面板：高德地图（显示茶园位置和病虫害标注点）、天气卡片（天气等级、详情和时间）、右侧面板：无人机视频画面、AI聊天区（对话显示区+文字输入框+发送按钮+🎤语音按钮）、顶部标题栏：智慧茶园综合管理系统和右下角系统托盘：阈值超限时弹出告警气泡等信息，并可依据页面显示继续处理。

使用该功能时，用户先系统启动后自动进入全屏主界面，左侧显示8张传感器数据卡片，数值每3秒自动刷新。用户可一眼查看茶园当前风速、空气温湿度、光照、土壤状况等全部环境指标，随后若 LoRa 串口未连接或数据中断，左侧底部状态标签显示连接状态提示，接着中间地图区域自动加载高德地图，显示茶园地理位置。当 YOLO 检测到病虫害时，地图上自动出现病虫害标记点。用户可拖拽、缩放地图浏览茶园周边地形，之后中间天气卡片显示当前天气预警等级和简要信息，点击卡片可展开查看24小时逐时天气预报详情，再右侧视频区域自动播放无人机 SRT 视频流画面。当 YOLO 推理完成后，有病虫害的视频帧会在画面中叠加检测框和类别标签，持续显示约2秒，继续需要开关灌溉泵时，点击左侧泵开关按钮（蓝色为开，灰色为关），按钮状态即时切换，LoRa无线指令发送至田间控制器。驱虫灯操作方式相同，继续需要设置定时灌溉或定时驱虫时，点击泵或灯按钮旁的⏰图标，弹出定时计划管理对话框，继续灌溉进行中时，左侧面板出现流量状态卡片，实时显示已灌溉量、预计总量和剩余时间，进度条动态更新。用户可点击停止按钮提前结束灌溉，或点击设置按钮调整流速，继续需要使用 AI 助手时，在右侧聊天输入框中输入问题（如“今天需要灌溉吗”），点击发送按钮或按回车键。AI回复显示在聊天区，继续需要使用语音输入时，点击🎤按钮开始录音，再次点击停止录音。系统自动将语音转为文字后发送给AI，回复显示在聊天区，继续需要查看数据趋势时，点击左侧📊按钮，弹出数据折线看板窗口，继续需要查看病虫害记录时，点击左侧🐛按钮，弹出病虫害监测看板窗口，最后需要遥控地面检测车时，点击左侧🚗按钮，弹出小车控制面板。

页面会按照 LoRa 串口需正确连接，否则传感器数值不更新、设备控制按钮间有800毫秒防抖间隔，连续快速点击会被限制和云端命令优先级高于本地定时计划，收到云端命令时取消当前定时任务等规则限制或提示用户。处理结束后，用户可以看到传感器数值实时刷新，正常数据显示为白色，超阈值数据显示为红色、设备按钮切换颜色和文字（开/关），按钮按下后状态即时反馈、LoRa状态标签显示当前连接端口和波特率、AI回复以聊天气泡形式显示在对话区，用户消息右对齐，AI回复左对齐、阈值超限时系统托盘弹出告警气泡，显示传感器名称和超限数值和灌溉进行中流量卡片动态刷新，进度条实时推进。

## 六、数据折线看板

用户可在数据折线看板页面以折线图形式展示8项传感器历史数据趋势，支持时间范围选择、阈值标记和 Excel 导出，帮助用户分析茶园环境变化规律。用户可以通过在主界面左侧面板点击📊数据看板按钮，弹出独立窗口。

茶园管理者或农业技术员需要回顾某段时间内的环境变化趋势时使用，例如查看过去24小时温度变化、对比本周与上周土壤湿度趋势。

该部分提供顶部工具栏：1小时/6小时/24小时/7天/30天时间预设按钮、自定义起始和结束时间选择器、查询按钮、阈值设置按钮、导出 Excel 按钮、主体区域：8张可折叠的折线图卡片（风速、空气温度、空气湿度、光照强度、土壤湿度、土壤温度、土壤电导率、土壤pH），每张卡片顶部有标题栏（点击可折叠/展开）、每张图表：折线数据线、超阈值红色散点标记、Y轴数值刻度、X轴时间刻度、底部横向滚动条：用于滑动浏览长时间范围的数据和图表卡片右下角：拖拽调整卡片高度的手柄等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

## 十二、常见问题解答

问题：传感器数据不更新怎么办？
解决方法：首先检查主界面左侧底部的 LoRa 状态标签，确认串口是否已连接。如果显示断开，检查 LoRa 模块 USB 连接是否松动，或尝试重新插拔 USB 数据通道。如果串口显示已连接但数据仍不更新，可能是传感器节点供电不足或距离过远，请检查传感器电池电量和安装位置。

问题：视频画面不显示或卡顿？
解决方法：检查无人机是否已开机并发送 SRT 视频流（默认端口9000）。如果网络不稳定，视频可能出现短暂卡顿，系统会自动重连。如果长时间无画面，尝试重启系统的视频流服务。地面检测车视频不显示时，检查 USB 摄像头是否正确连接到设备 USB 口。

问题：如何设置每天自动灌溉？
解决方法：在主界面点击灌溉泵按钮旁的⏰图标，打开定时计划管理对话框。点击新增计划，选择设备类型为灌溉泵，勾选需要执行的星期（如周一至周日全选），设置灌溉开始时间和持续时长（分钟），勾选启用，点击确认保存。系统会在设定的时间自动开启灌溉泵，到达时长后自动关闭。

问题：AI对话功能无法使用？
解决方法：AI对话功能需要互联网连接和有效的DeepSeek API密钥。如果无法使用，请检查设备网络连接是否正常，确认 API 密钥配置是否正确。网络正常但 AI 仍无回复时，可能是 API 服务暂时不可用，稍后重试即可。

问题：病虫害检测结果不准确？
解决方法：YOLO检测准确率受视频画面质量、光照条件和拍摄距离影响。如果漏检较多，建议在光照充足的时间段飞行无人机，保持适当的飞行高度（建议3-5米）。如果误检较多，可在配置文件中适当调高检测置信度阈值。

问题：数据会丢失吗？
解决方法：所有传感器数据和病虫害检测记录都存储在设备本地 SQLite 数据库中，断电或重启不会丢失。如需长期保存，建议定期使用数据看板的 Excel 导出功能备份数据。同时，数据会上报华为云 IoTDA 平台，云端也有数据副本。
