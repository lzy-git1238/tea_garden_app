# 业务理解

- 软件名称：智慧茶园综合管理系统
- 产品定位：基于RK3588边缘AI开发板的茶园全场景智能管控平台，集环境感知、视频分析、设备控制、云平台协同和AI决策于一体，面向茶园数字化转型提供一站式边缘计算解决方案。
- 面向领域 / 行业：智慧农业 / 物联网应用 / 边缘计算与人工智能
- 核心价值：将边缘AI推理（YOLO病虫害检测）、LoRa物联网感知、MQTT云平台协同和DeepSeek大语言模型深度融合，替代传统人工巡检，实现茶园环境实时监控、病虫害自动识别、设备远程控制和AI智能决策，降低人力成本，提升管理效率。
- 证据文件：`业务理解证据.md`

## 目标用户

- 茶园管理人员：日常巡检、环境监控、灌溉和驱虫灯控制
- 农业技术人员：病虫害监测数据分析、灌溉方案制定
- 农场经营者：远程查看茶园状态、接收异常告警

## 主要业务功能

- 茶园环境实时监控
- 无人机视频与地面小车视频采集
- YOLO病虫害AI检测与地图标注
- 灌溉泵与驱虫灯控制
- 传感器历史数据看板
- 华为云IoTDA双向通信
- AI智能管家
- 地面检测车遥控
- Web远程监控
- 天气预警

## 功能说明

- 茶园环境实时监控：通过LoRa无线网络采集茶园中部署的传感器节点数据，包括空气温湿度、光照强度、风速、土壤湿度/温度/电导率/pH共8项环境指标，在主界面以数据卡片形式实时展示，每3秒刷新一次。
- 无人机视频与地面小车视频采集：通过SRT协议接入农业无人机H.264视频流，利用RK3588硬解码实时播放；同时通过USB摄像头采集地面检测车巡检画面，在主界面视频区域显示。
- YOLO病虫害AI检测与地图标注：无人机和检测车视频帧送入RK3588 NPU上运行的YOLOv5s病虫害检测模型，实时识别茶藻斑病、茶炭疽病、茶灰斑病、茶小绿叶蝉、茶红叶斑等6类目标，检测结果关联GPS坐标后在高德地图上标注展示。
- 灌溉泵与驱虫灯控制：支持四种控制模式——主界面按钮一键手动开关、定时计划自动执行（支持按星期多时段配置）、传感器阈值超限联动触发、华为云IoTDA远程命令下发。灌溉进行中显示实时流量状态卡片。
- 传感器历史数据看板：8项传感器各自一张折线图，支持1小时/6小时/24小时/7天/30天时间预设和自定义时间范围查询，图表可折叠展开。每项传感器可设置上下限阈值，超限数据点以红色标记，同时触发系统托盘弹泡告警。支持导出Excel。
- 华为云IoTDA双向通信：通过MQTTS协议将传感器数据、病虫害统计、设备状态上报至华为云IoTDA平台，同时接收云端下发的pump_control和light_control命令，实现远程设备控制。
- AI智能管家：集成DeepSeek大语言模型，用户可在主界面右侧聊天区通过文本输入或语音（SenseVoice语音识别）与AI对话，获取茶园管理建议、灌溉方案推荐、病虫害防治指导等智能服务。
- 地面检测车遥控：通过独立控制面板，使用键盘WASD键或屏幕按钮网格发送LoRa指令遥控地面检测车行进（前进/后退/左转/右转/喷水），同时实时显示检测车USB摄像头画面。
- Web远程监控：内置HTTP服务器（端口8080）和WebSocket服务（端口8081），支持浏览器远程访问，实时推送传感器数据和设备状态。
- 天气预警：调用星图云API获取24小时逐时天气预报，在主界面天气卡片中展示，支持气象预警信息推送。

## 典型操作流程

1. 系统启动 → 全屏显示主界面三栏布局（左侧：传感器数据卡片+设备控制按钮；中间：高德地图+天气卡片；右侧：视频画面+AI聊天区）
2. LoRa自动连接 → 每3秒接收传感器数据 → 更新左侧数据卡片数值 → 同步存入SQLite数据库 → 上报华为云IoTDA
3. 无人机视频接入 → SRT拉流硬解码 → 视频帧送YOLO推理 → 检测结果标注在地图 → 病虫害记录存入数据库
4. 手动控制设备 → 点击泵/灯按钮 → LoRa下行发送开关命令 → 设备状态上报云端
5. 定时调度 → 打开定时管理对话框 → 新建/编辑计划（设备类型、星期、时间、时长） → 系统每分钟检查 → 到时自动执行
6. 查看历史数据 → 点击📊按钮 → 打开数据看板 → 选择时间范围 → 查看折线图 → 可选导出Excel
7. AI咨询 → 在聊天区输入问题或点击语音按钮录音 → 发送至DeepSeek API → 显示AI回复

## 操作手册页面/流程模块

1. 主界面仪表盘：系统启动后自动全屏显示，无需手动进入。
   - 使用场景：茶园管理人员打开系统后在此页面查看茶园实时环境数据、无人机/检测车视频画面、地图标注和天气信息，进行设备开关操作和AI咨询。
   - 操作要点：系统启动后自动进入全屏主界面，左侧显示8张传感器数据卡片，数值每3秒自动刷新。用户可一眼查看茶园当前风速、空气温湿度、光照、土壤状况等全部环境指标。；若LoRa串口未连接或数据中断，左侧底部状态标签显示连接状态提示。；中间地图区域自动加载高德地图，显示茶园地理位置。当YOLO检测到病虫害时，地图上自动出现病虫害标记点。用户可拖拽、缩放地图浏览茶园周边地形。；中间天气卡片显示当前天气预警等级和简要信息，点击卡片可展开查看24小时逐时天气预报详情。
2. 数据折线看板：在主界面左侧面板点击📊数据看板按钮，弹出独立窗口。
   - 使用场景：茶园管理者或农业技术员需要回顾某段时间内的环境变化趋势时使用，例如查看过去24小时温度变化、对比本周与上周土壤湿度趋势。
   - 操作要点：在主界面点击📊按钮，弹出数据折线看板窗口，默认显示最近1小时的8张传感器折线图。；点击顶部1小时/6小时/24小时/7天/30天预设按钮，图表自动切换到对应时间范围。当前选中按钮高亮显示。；需要自定义时间范围时，在起始时间和结束时间选择器中分别选择日期和时间，点击查询按钮，图表按指定范围刷新。；图表中蓝色折线表示传感器数值随时间的变化趋势。若设置了阈值，图表中显示红色虚线上限和/或下限，超限数据点以红色大圆点标记。
3. 病虫害监测看板：在主界面左侧面板点击🐛病虫害按钮，弹出独立窗口。
   - 使用场景：茶园管理者需要查看已检测到的病虫害种类分布和发生记录时使用，例如查看本周茶小绿叶蝉的发生次数和位置分布。
   - 操作要点：在主界面点击🐛按钮，弹出病虫害监测看板窗口。；窗口顶部显示自系统运行以来累计检测到的病虫害总次数。；左侧饼图以不同颜色扇形展示各病虫害种类的占比，鼠标悬停在扇形上可看到具体种类名称和次数。；右侧表格逐行列出每条检测记录，包含病虫害种类名称、检出数量、GPS经纬度坐标和检测时间。
4. 地面小车控制面板：在主界面左侧面板点击🚗小车控制按钮，弹出独立控制面板窗口。
   - 使用场景：茶园管理者需要遥控检测车进入茶园深处巡检、查看作物状况或执行喷水作业时使用。
   - 操作要点：在主界面点击🚗按钮，弹出小车控制面板窗口，上半区域显示检测车USB摄像头的实时画面。；使用键盘WASD键控制小车：按W前进，按S后退，按A左转，按D右转。按住按键时小车持续运动，松开后停止。；也可使用鼠标操作：按住屏幕上的方向按钮不放，小车持续朝该方向运动；松开按钮后小车停止。按钮按下时高亮显示，松开恢复。；需要喷水时，按T键或点击屏幕上的喷水按钮，小车开始喷水。按F键或再次点击喷水按钮停止喷水。
5. 定时计划管理：在主界面左侧面板点击泵或灯按钮旁的⏰图标，弹出定时计划管理对话框。
   - 使用场景：茶园管理者需要设置周期性自动灌溉或驱虫时使用，例如设置每天上午8点和下午6点各灌溉30分钟。
   - 操作要点：点击主界面泵或灯按钮旁的⏰图标，弹出定时计划管理对话框。设备筛选框自动对应当前点击的设备类型。；查看已有计划：在计划管理标签页的表格中浏览所有已配置的定时计划，包括设备类型、执行星期、时间、持续时长和启用状态。；新建定时计划：点击新增计划按钮，弹出计划编辑子对话框。在子对话框中选择设备类型（灌溉泵或驱虫灯），勾选执行的星期（周一至周日可多选），设置执行时间（时:分），输入持续时长（分钟），勾选是否启用，点击确认保存。；编辑已有计划：在计划表格中双击某一行或选中后点击编辑按钮，弹出预填当前设置的编辑子对话框，修改后点击确认。
6. 阈值设置：在数据折线看板窗口点击阈值设置按钮，弹出阈值设置对话框。
   - 使用场景：茶园技术人员根据茶树生长环境要求设置各传感器的合理范围，例如设置土壤湿度下限为30%（低于此值需灌溉），温度上限为35℃（高于此值需降温通风）。
   - 操作要点：在数据折线看板窗口点击阈值设置按钮，弹出阈值设置对话框。；对话框列出8项传感器，每项有下限和上限两个输入框。已配置的阈值显示当前数值，未配置的显示为空。；在需要设置阈值的传感器行中输入下限值和上限值。例如在土壤湿度行下限框输入30，上限框输入80。；点击保存按钮，阈值写入配置文件并立即生效。返回数据看板后，图表中出现红色阈值线和超限标记点。
